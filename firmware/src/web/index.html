    Wi-Fi

    Not checked

    Save up to two networks. Saving does not reconnect: verify the saved names, then choose Reconnect. The address may change.

    Offline setup: on the device, open Settings → Wi-Fi → Start portal. Portal activation remains physical-only.

    Home network
    Hotspot network

    Blank password keeps the saved password for an unchanged SSID. For a new SSID, enter 8–63 printable ASCII characters or explicitly choose open. Blank SSID disables that slot; keep at least one network. Passwords are never read back.

    Transcription server

    Use the server address, not this device’s address. Saved on the device for live and final transcription.

    HTTP sends audio and the token in plaintext: use a trusted LAN only. No path, login, query or fragment. An IPv4 without a port uses HTTP port 8080. An explicit origin preserves its protocol and port.

    Write-only. Blank keeps the current token. This is the LXC server token, not your local access code.

    Usage unknown

    Retry never formats. Erase requires a mounted, responsive FAT card and stopped recording/transcription workers. Unmountable cards need external formatting.

    Erase all SD card data?

    All audio, transcripts and other card files will be erased. This cannot be undone. Confirmation expires after 60 seconds.

    Unlock your device

    On the ESP32, open Settings → Wi-Fi → Open web settings. Enter the six-digit PIN shown on its screen. Access lasts 10 minutes. After 5 incorrect attempts, reopen web settings on the device. This is not your transcription server token.
